# AULA - GIT

### comandos básicos

Autentificar via computador local no GitHub

```

gh auth login 
```

Clonar repositório no GitHub:
```

gh repo clone nome_do_repoitório
```
Abrir Vs Code:
```

code .
```

### Salvar no GitHub

Preparar arquivos para salvar:
```
gti add .
```
Comando para versionar (salvar):
```

gti commit -m "mensagem"
```

Enviar para o GitHub:
```
git push
```
